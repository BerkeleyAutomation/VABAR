# Scissor 1 compound collision proxy

These 30 OBJ files are collision-only components generated by
`tools/build_scissor_1_compound_collision.py`. Each file is a closed convex
mesh in metres and in the local frame of `scissor_1.obj`.

The two handles use twelve overlapping short prisms apiece. No component spans
an opening, so the hook can pass through a handle without relying on concave
triangle-mesh collision. Six additional prisms represent the necks, blades,
pivot, and central bridge. The original OBJ remains the sole visible mesh and
the source of body mass and inertia.

Run the generator again after changing its measured footprints. It validates
watertightness, convexity, winding, and writes `manifest.json` with component
bounds and triangle counts.

Run it with `--plot` to also write `collision_method_comparison.png`. The
middle panel reconstructs the former 3,499-triangle QEM result in memory for
comparison; it does not restore that obsolete mesh as a simulation asset.
