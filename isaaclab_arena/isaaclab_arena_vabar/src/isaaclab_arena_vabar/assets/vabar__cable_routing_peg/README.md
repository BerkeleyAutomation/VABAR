# ManipulationNet cable-management pegs

USD peg assets for the ManipulationNet Cable Management Benchmark:

- `round_peg.usdc`: the F1 round-peg mesh and a three-cylinder compound collider for its `9.5 mm` waist and `25 mm` flanges.
- `orange_round_peg.usda`: the orange peg used by cable routing easy. It collides with the F1 triangle mesh instead of the three cylinders, and binds friction 2, stiffness 10000, damping 0.1 and contact gap 0.01 m directly on its collider.

Both files are self-contained, metre-scale, Z-up, kinematic rigid components.
