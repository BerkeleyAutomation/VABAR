# Pegboard screwdriver box

The open box that holds screwdrivers on the tool-hanging pegboard, from Berkeley AUTOLab's tool-hanging assets (Apache-2.0).

Eleven convex boxes form the floor, four walls and two mounting straps; the interior is open. Coordinates are metre-scale. Registry: `vabar__screwdriver_box`. Easy-task pose: position `(0.88, 0.0732, 0.85)`, quaternion XYZW `(0, 0, 1, 0)`.
