# RSS cable-task appearance

Visual-only room, bench and lighting matching AUTOLab's RSS cable tasks (Apache-2.0). Textures are copies of the RSS procedural concrete and plaster.

The bench is centred at `(0.6, 0, 0.375)`, with half-extents `(0.2975, 0.65, 0.375)` and matte colour `(0.28, 0.28, 0.29)`. The default STUDIO look uses ambient 1.5 (dome intensity 1350), panel intensity 5000, and no HDR panorama. The scene places it with the RSS-to-Arena offset `(-0.5875, 0, 0.017)`.

It has no collision or rigid-body APIs; the invisible table collider remains the physics source. Easy hides its metallic table and warehouse light; Medium is unaffected.
