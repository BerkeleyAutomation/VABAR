# Insert the routed cable’s free end

Use the observed curve and terminal/tail RGB-D helpers to choose a feasible free-end grasp. Execute the routine’s bounded grasp, feed, insertion, and release sequence.

Terminal geometry must come from observations. Plugged means the routine finished; the evaluator still checks physical port occupancy after settling. Preserve the current retry bounds when composing the recipe. The current outer graph runs visual verification even after unplugged; keep the terminal failure visible alongside that visual route claim.

Check the full terminal mask in the selected renderer. Tiled orange fittings have hue 9; excluding that hue leaves only highlights and incorrectly suppresses the insertion attempt. Missing visual evidence means the terminal was not detected, not that the layout has no port.

For fixed-end Easy (two pegs) and Medium (four pegs), use only the fixed third-person cable RGB-D camera for fixture detection, centreline tracking, grasp refinement, terminal placement, and verification. Do not use overhead or wrist fallbacks; if the cable view is occluded, retain the measured prior or report lost evidence.

Reject apparent cable tips at orange fixture occlusions before correcting terminal placement; use the same orange hue range as fixture perception. After releasing and retreating, let the cable settle before measuring the terminal tail so a temporarily raised tip is not mistaken for lost visual evidence.
