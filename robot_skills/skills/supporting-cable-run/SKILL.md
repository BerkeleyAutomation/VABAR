# Establish cable support

Read the observed curve and ask cable.plan_support for the rig and grasp plan. For both routing Easy and Medium, start_fixed is true: return anchored with empty q_support and quat, without closing a support gripper. The physical bench fixture already fixes end_a.

For a free-start diagnostic layout, execute the planned support approach, close through contact friction, and export the commanded support configuration for feed planning. This conditional recipe never installs a latch or weld on the hand.

For fixed-end Easy (two pegs) and Medium (four pegs), use only the fixed third-person cable RGB-D camera for fixture detection, centreline tracking, grasp refinement, terminal placement, and verification. Do not use overhead or wrist fallbacks; if the cable view is occluded, retain the measured prior or report lost evidence.
