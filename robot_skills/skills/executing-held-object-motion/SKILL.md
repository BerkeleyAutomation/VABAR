# Carry a cable crossing with support feed

Use run_legs with the carry-phase arguments. Read the previous commanded support joint state from cable.support_memory and pass the measured plan into cable.carry_with_feed.

Both routing Easy and Medium have a fixed start and skip the initial support grasp, so their crossing carry uses the selected work arm with empty q_support. When another layout supplies a support configuration, cable.carry_with_feed schedules the support joint trajectory. Preserve the measured material/slack fields; these are motion commands, not cable forces or attachments.

For fixed-end Easy (two pegs) and Medium (four pegs), use only the fixed third-person cable RGB-D camera for fixture detection, centreline tracking, grasp refinement, terminal placement, and verification. Do not use overhead or wrist fallbacks; if the cable view is occluded, retain the measured prior or report lost evidence.

For a fixed end with no support-feed trajectory, stream the consecutive carry and crossing waypoints as one continuous motion. Avoid inserting a settling pause at every short arc segment.
